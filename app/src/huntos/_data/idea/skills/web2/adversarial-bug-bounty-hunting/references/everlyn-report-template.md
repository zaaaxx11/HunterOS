# Everlyn Report Template (Human Tone, No AI Slop)

## Opener (English)
Hey [Name],

Hope you're doing well. I spent some time looking at [target]'s security and found a few things I think you should know about.

The short version: [one sentence summary of the most critical finding].

Here's what I found:

## Each Finding Format
[PLAIN ENGLISH DESCRIPTION — no bullet lists, just paragraphs]

[INLINE POC COMMAND — copy-paste ready]

[ONE SENTENCE IMPACT — no "IMPACT:" label, just say it]

## Closing
I haven't shared this anywhere. I wanted to tell you first. If you have a bug bounty program or any questions, I'd be happy to talk.

Thanks,

## Rules
- NO dashes/separators (=== or ---)
- NO AI slop phrases ("critical vulnerability", "attack vector", "mitigation strategy")
- NO labels like "IMPACT:", "EVIDENCE:", "CONFIDENCE:"
- Casual, human, direct — like you're emailing a colleague
- Include POC commands inline in the description
- Use blank lines between sections, nothing else
