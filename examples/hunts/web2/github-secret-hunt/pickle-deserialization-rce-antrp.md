## WHY PICKLE IS DANGEROUS

```python
class EvilPickle:
    def __reduce__(self):
        # Returns (callable, args) — executed during pickle.load()
        return (os.system, ("malicious command",))
        # Or:
        return (subprocess.run, (["/bin/sh", "-c", "cmd"],), {"shell": True})
        # Or:
        return (eval, ("__import__('os').system('cmd')",))
        # Or any callable with controlled args
```

**Pickle is NOT a data format** — it's a serialization of **executable Python objects**.

## MITIGATION PATTERNS

```python
# SAFE: Use JSON instead of pickle
import json
with open(args.cache, 'r') as f:
    evaluator = json.load(f)

# SAFE: torch.load with weights_only=True (PyTorch 2.0+)
evaluator = torch.load(args.cache, map_location='cpu', weights_only=True)

# SAFE: Safetensors (industry standard for ML)
from safetensors.torch import load_file
evaluator = load_file(args.cache)

# SAFE: Add HMAC signature verification
import hmac, hashlib
def verify_cache(path, secret):
    with open(path, 'rb') as f:
        data = f.read()
    sig = data[:32]
    content = data[32:]
    expected = hmac.new(secret, content, hashlib.sha256).digest()
    return hmac.compare_digest(sig, expected)

# SAFE: Restrict to specific class (limited protection)
import pickle
class SafeUnpickler(pickle.Unpickler):
    def find_class(self, module, name):
        if module == "builtins" and name in {"list", "dict", "str", "int", "float"}:
            return super().find_class(module, name)
        raise pickle.UnpicklingError(f"Unsafe class: {module}.{name}")

SafeUnpickler(open(args.cache, 'rb')).load()
```

## LESSONS LEARNED

1. **Never trust user-controlled file paths for deserialization**
2. **Pickle is executable code, not data** — treat as such
3. **`os.path.exists()` is NOT validation** — only checks existence
4. **CLI tools are attack surface** — arguments = user input
5. **Research code != production-hardened** — often missing basic authz
