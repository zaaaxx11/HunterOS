# U2U Network Hunt — 2026-08 (multi-target CDC case study)

Target: U2U Network (Fantom/aBFT-style L1, chain ID 39, `rpc-mainnet.uniultra.xyz`, go-u2u node fork `go-u2u/v1.1.3`). 71 GitHub repos, mainnet live at block ~66M. Method: 5 sequential targets × 4 CDC subagents each (Architect / Red-Teamer / Fuzz-Engineer / Chainer).

## 1. Public RPC debug-namespace probing (PROVEN LIVE)

**Existence oracle:** call `{"method":"<m>","params":[]}` —
- `-32602 missing value for required argument 0` = method EXISTS (add args to exploit)
- `-32601 the method ... does not exist/is not available` = blocked

**OPEN on U2U mainnet public RPC (zero auth):** `debug_stacks` (full goroutine dump — leaks internal build paths `/go/go-u2u/...`, Go version, pebble dep), `debug_memStats` (1.6GB heap, GC pressure), `debug_gcStats`, `debug_writeMemProfile`, `debug_cpuProfile`, `debug_writeBlockProfile`, `debug_goTrace`, `debug_blockProfile`, `debug_mutexProfile`, `debug_setGCPercent`, `debug_verbosity`, `debug_backtraceAt`, `debug_freeOSMemory`, `debug_traceCall`, `debug_traceBlockByNumber/Hash`, `txpool_content` (152 queued txs, 68 addrs incl. 5000-U2U transfers — MEV/front-run oracle).

**Arbitrary file write (limited content):** `debug_writeMemProfile("/proc/self/environ")` → `null` = success. Root cause `debug/api.go:writeProfile()` → `os.Create(expandHome(file))`; `expandHome` only expands `~/`, NO path restriction. Writes binary pprof to ANY writable server path → log/config/state corruption, `/proc/self/*` tampering, DoS. Ceiling: content not attacker-controlled → not direct RCE. `/etc/cron.d/x`, `/root/.ssh/x` failed only because dirs absent in the container.

**DoS primitives:** `debug_setGCPercent(-1)` (disable GC → OOM), repeated `debug_freeOSMemory` (GC thrash), `debug_cpuProfile` with huge nsec (disk fill).

**Blocked on aBFT chains:** `debug_setHead` → "helios cannot rewind blocks due to the BFT algorithm". `admin_*` / `personal_*` not exposed over HTTP.

**goja JS tracer is NOT arbitrary JS execution:** `newJsTracer` only resolves built-in asset tracers — `callTracer`, `prestateTracer`, `4byteTracer`, `noopTracer`, `bigramTracer`, `trigramTracer`, `unigramTracer`. Custom `{step:...}` code → "tracer not found" (no `require("fs")` RCE path). But `prestateTracer` on `debug_traceCall` = read ANY contract's storage slots pre-auth (leaked SFC proxy impl address `0xfc01face...` from slot 0x80).

## 2. Contract findings (subnet-contracts repo)

- **SubnetStakingPool reward-history DoS (CRITICAL):** `updateRewardRate()` (L207-217) pushes `rewardRateHistory[]` snapshots unbounded, no cap/cooldown (~45k gas/call). `_pendingReward()` (L116-143) loops linearly from `userLastSnapshotIndex`; stake/withdraw/claimReward ALL route through the `updateReward` modifier. Stale user + thousands of snapshots → OOG → funds locked permanently. No escape hatch. Fix: Synthetix `rewardPerTokenStored` accumulator (O(1)).
- **Owner rug vectors (by design, flag as centralization):** `updateRewardRate(1)`, `updateEndTime(now+1)`, rate-sandwich right before user claims.
- **PRECISION_FACTOR decimals flaw (MEDIUM):** `PRECISION_FACTOR = 10**decimals(stakingToken)` while reward math is `staked*rate*time/PRECISION` — staking 6-dec / reward 18-dec mismatch → rate set 10^12× wrong by admin mistake.
- **SubnetBidMarketplace.claimPayment (HIGH):** no caller check — anyone triggers settlement; `lastPaidAt = endTime` written BEFORE the token transfer (revert → payment window lost, funds stuck).
- **SubnetProvider.claimWithdrawal (HIGH):** `IERC20(stakingToken).safeTransfer(msg.sender, amount)` — missing `isProviderOperatorOrOwner` check; anyone steals any provider's unlocked stake.
- **SubnetProvider.slashStake + withdrawSlashedFunds (centralization):** owner slashes 100% of any stake, withdraws proceeds to self. No timelock/governance/cap.
- Confirmed SAFE patterns (don't re-report): new staker past-reward = 0 (modifier runs with staked=0 before increment); claimReward CEI correct (userRewards zeroed before transfer); factory `createPool` is onlyOwner.

## 3. aa-bundler (eth-infinitism fork, ERC-4337) — grep-able bug patterns

- **DepositManager double-sub (CRITICAL):** `DepositManager.ts:23-28` — mempool loop does `deposit.sub(getUserOpMaxCost(userOp))` using the OUTER `userOp` instead of `entry.userOp` → paymaster deposit over-counted → paymaster bankruptcy → bundler-wide DoS. Pattern: loop body referencing the request-scoped variable instead of the loop variable in accounting code.
- **MempoolManager inverted sort (HIGH):** `getSortedForInclusion` sorts `cost(a)-cost(b)` ascending → LOWEST-fee ops bundled first → economic DoS + front-run enabler. Check sort comparator direction on every bundler fork.
- **`debug_bundler_*` no-auth + CORS `*` (HIGH):** `dumpMempool`, `clearState`, `setReputation` publicly callable when `debugRpc=true` → public mempool surveillance + state wipe.
- **Economic surface:** `preVerificationGas=0` accepted → bundler subsidizes; `estimateUserOperationGas` honors caller `stateOverride` → gas-estimation manipulation; address regex `{10,40}` accepts short addresses; signature length not pinned to 65.
- Confirmed safe: sig bypass blocked by EntryPoint `simulateValidation` (`sigFailed` from merged account+paymaster aggregator); replay blocked by chainId+nonce; `--unsafe` flag skips opcode/stake checks — verify it's OFF in prod.

## 4. dhcp2p (REST "DHCP" for libp2p) + network-stats — cross-surface chain

dhcp2p is NOT wire DHCP — HTTP API: `POST /request-auth` (unauth nonce) → sign `sha256(nonceID)` with libp2p key → `POST /allocate-ip`. Pool ~260K sequential tokenIDs (migration `max_token_id=168162304`) → deterministic `10.0.0.0/8` mapping.

- **Sybil starvation (CRITICAL):** keypairs free; rate limit per source-IP NOT per-peerID → rotate IPs → exhaust 260K pool → newcomers locked out → network partition. No lease sweeper; renew endpoint has no frequency cap; allocation is a single-row global mutex (`UPDATE alloc_state ... WHERE id=1`).
- **Public lease enum (HIGH):** `GET /lease/peer-id/{id}`, `GET /lease/token-id/{id}` unauth → full peer↔token↔TTL topology map.
- **Expired-lease reuse without re-auth (HIGH):** `FindExpiredLeaseForReuse` hands a dead validator's IP to whoever asks first → validator-IP squatting → gossip MITM / isolation.
- network-stats (Go node-crawler fork): unauth `0.0.0.0:10000/v1/dashboard` (client/OS/version/country intel), pprof `/debug/pprof/*` open, no rate limit, no panic recovery, heavy-filter → 5 SQL queries/req resource exhaustion. SQLi mitigated by identifier whitelist + prepared statements; XSS dormant (React auto-escape everywhere).

**Kill chain (the point of the exercise):**
```
debug_stacks/memStats → identify validators + node internals
  → network-stats /v1/dashboard → peerID↔version↔geo map
  → dhcp2p public lease read → validator IP + lease TTL
  → Sybil squat expired lease / starve pool
  → >1/3 validators isolated → aBFT consensus halt
```
Each link LOW-MED alone; chained = network-level. Report the chain, not the list.
