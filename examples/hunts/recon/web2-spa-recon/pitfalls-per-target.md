## Pitfalls — AIOZ 2026-08 Lessons

**SPA 200 Trap — 200 ≠ endpoint exists.** Next.js catch-all returns `200 text/html <!DOCTYPE` for every `/api/*`, `/admin`, `/swagger`, `/graphql`. `web2-deep.py v3` flagged 13 🔥 on `explorer.aioz.network` + `wallet` + `bridge` but all were HTML fallback. Rule: validate `Content-Type: application/json` + body `{"message":"Not Found"}` vs `{"success":true}`. Real `api-explorer.aioz.network` only had 4 JSON (`/api/status` `{"success":true,"total_block":24755k}`, `/api/blocks`, `/api/transactions`, `/api/token/aioz/all`); rest 404. Wallet/bridge SPAs have 0 real APIs — don't report count without body.

**Open-proxy (CORS bypass) ≠ internal SSRF.** `rpc-proxy.aioz.services/rpc?q=URL` fetches ANY public (`https://example.com` → Example Domain ✅, `api-explorer/status` → JSON ✅) proving open proxy, but `127.0.0.1:80/3000/8545/26657` → `dial tcp ... connection refused`, `169.254.169.254` → `not found`, `metadata.google.internal` → `no such host`. Means container has no localhost listener / no IMDS, not WAF `403`. Distinguish `connection refused` (pod empty) from `filtered/forbidden` (blocked). It's a CORS proxy for `wallet` (`?q=https://rpc.osmosis.zone`), not VPC SSRF. URL-encoded `%30%2E` not decoded.

**JS chunks hide real backends.** `aioz.network` 23 chunks (903k), `explorer` 21 chunks (2.4M) — `grep -oE 'https://[^\s"'\'']+'` leaked 8 bases (`api-explorer`, `eth-dataseed 0x179bcb7`, `lcd-dataseed height 24755381`, `rpc-proxy`). SPA probe on main domain misses them.

**Firebase public keys.** `AIzaSy…ytvc` (`aioz-blockchain`) + `…qerI` (`wallet-cbada`) are public config — triage via Firestore rules open-read, not key leak.

**Stub repo false surface.** `w3s-gateway` 4 files README-only — don't audit as attack surface.

## Pitfalls — aelfscan / Next.js App Router 2026-08

**App Router vs Pages Router.** No `__NEXT_DATA__` and `/_next/data/<buildId>/tDVV.json` returns `200 text/html` (RSC fallback). BuildId still leaks in RSC flight payload: `grep '"buildId"'` after `unicode_escape` decode → `765LcKFhazqx70vKx8g_p` on `aelfscan.io/tDVV`. Validate by `curl -A Mozilla -s https://aelfscan.io/_next/data/<id>/tDVV.json | head -c 200` — `<!DOCTYPE` means App Router; stop treating it as JSON data source.

**UA-gated chunks.** `/_next/static/chunks/*.js` → `403 Forbidden` via `urllib`/`python-requests` default UA; `curl -A "Mozilla/5.0"` returns `200`. Also need `-H "Referer: https://aelfscan.io/tDVV"` for some API calls. Always set Mozilla UA when bulk-downloading chunks.

**ABP pagination (`SkipCount`/`MaxResultCount`), not `pageNum`.** `aelfscan.io/api/app/address/contracts?chainId=tDVV&pageNum=2` returns same first page forever (silent pagination bug). Correct form: `?chainId=tDVV&SkipCount=0&MaxResultCount=50` (iterate `skip+=50` until `len(batch)<50`). `total:141` on tDVV, `51` on AELF. Same pattern on `/contract/history` etc.

**Real API map hidden in one chunk.** 29 chunks; only `9118-0e78938...js` held `let r="/api", c="".concat(a.env.NEXT_PUBLIC_API_URL,"/api")` and the `Object.entries({block:{...}, address:{getContractList:r+"/app/address/contracts", getServerContractList:c+"/app/address/contracts"}, ...})` table. Scan all chunks in parallel with UA, then grep for `aelfscan.io/api`, `/api/app/`, `getContract`, `contractList` — not just `https://`.

**Bridge disambiguation by `contractName`.** tDVV has **no active `EBridge.Contracts.Bridge`** (AELF does at `2dKF3s...` with 41k txns). tDVV only shows `DeprecatedBridge` (`8Xmxca...`), `DeprecatedEBridge*` quartet, plus live `ETransfer.Contracts.TokenPool` (`x4CTSu...`, 26k txns) and `AElf.ContractNames.CrossChain` (system, 7.6M txns). `contractName: null` for 112/141 rows — filter by `contractName` keyword, not address regex `2*` (all AElf addresses match).

## Pitfalls — BC Swap / BC Launchpad Multi-API Ecosystem (Vite + Cloudflare + 4 Express backends) 2026-08-16

**`baseURL`-grep reveals the entire backend API fleet.** When a Vite SPA uses `axios.create({baseURL:'https://...'})` (or `yL.create` in minified form), `grep -oP 'baseURL.{0,80}'` on the main bundle dumps EVERY backend subdomain in one shot. Then trace each variable (`rW`, `iW`, `oEe`) to its routes via `grep -oP 'rW\.(get|post|put|delete)\(...'`. bcswap's 3.3MB `index-DePTGhDw.js` yielded `bchscan.io`, `bcmonitorapiv2.bchscan.io`, `swapmonitapi.bchscan.io`, and `adminapi.bchscan.io` — four separate Express backends from one grep. Full session: `./bcswap-launch-redteam-2026-08.md`.

**Express catch-all `{"success":true,"message":"API is working"}` is a decoy.** `token.pnexplore.com` and `adminapi.bchscan.io` return this for every path — even nonexistent ones. The real endpoints are on the other subdomains. Distinguish the catch-all from real route-not-found responses (`{"success":false,"error":"Route not found"}` on `bcmonitorapiv2`).

**Wallet-address-as-auth without signature verification.** `swapmonitapi.bchscan.io/event/create` accepts `connectedWalletAddress` as a plain body field — no cryptographic proof the caller owns the wallet. Combined with CORS `*`, anyone can spoof events for any wallet. This is a distinct auth-failure class from JWT/session bypass — hunt for `connectedWalletAddress`/`walletAddress`/`userAddress` in POST body params with no signature/nonce/`eth_sign` verification.

**Raw RPC node ≠ JSON-RPC proxy.** `rpc.bchscan.io` is the actual Go Geth node with `debug` module exposed; `mainapi.bchscan.io` is a separate JSON-RPC proxy that handles methods differently. Always probe both — the proxy may block `debug_*` while the raw node doesn't. BC Swap: `mainapi` has `debug_traceBlockByNumber` but not `debug_writeMemProfile`; `rpc.bchscan.io` has the full debug arsenal including file write and GC control. The `debug_stacks` goroutine dump confirmed `consensus`/`p2p`/`seal` keywords → validator node, not just public RPC. `debug_writeMemProfile("/tmp/test.prof")` returning `result:null` is the success case — file WAS written.

## Pitfalls — WordPress + Simply.com WAF PoW + CORS Reflect (partisiafoundation.com 2026-08-15)
